# Interpretation guidance

- State classes are contextual benchmark positions, not complete ecosystem-condition or degradation classes.
- High whole-map agreement can coexist with low Poor-class overlap.
- Trend classes represent statistically qualified NDVI direction, not causality.
- Full-period Trend can retain persistence while concealing recent onset or reversal.
- Performance classes represent displacement from the fixed baseline, not monotonic direction.
- Joint groups organise evidence and do not determine intervention priority.
- Class 11, Natural vegetation mosaic, should not be used as the main example of a homogeneous LULC response.

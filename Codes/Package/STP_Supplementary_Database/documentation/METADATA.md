# Metadata

## Spatial basis

All summaries use the common equal-area 250-m raster grid. Percentages use the common valid domain for the relevant comparison and reporting unit.

## Reporting levels

Country; ecoregion; major LULC; country × LULC; ecoregion × LULC.

## LULC class 11

Label: **Natural vegetation mosaic**.

The code remains 11 and no original analysis is altered. The class includes CCI 100 and 110 plus minor class 140. It is structurally heterogeneous and requires cautious interpretation.

## Missing and suppressed values

A missing Jaccard or kappa is not automatically zero. It can indicate insufficient area, absence of the focal class, or insufficient class variation.
